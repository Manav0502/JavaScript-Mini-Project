# VelvetClean Laundry Service Website

A small frontend project for a premium laundry service booking page built using HTML, CSS, and JavaScript.

## Features
- Hero section with service CTA
- Laundry services listing
- Add/remove items from cart
- Total amount calculation
- Booking form with customer details
- Newsletter form
- Responsive design for desktop and mobile
- EmailJS integration for booking email

## Tech Stack
- HTML
- CSS
- JavaScript
- EmailJS
- Font Awesome

## Files
- `index.html` – page layout and sections
- `style.css` – styling and responsive layout
- `email.js` – service data, cart logic, booking form logic
- `README.md` – project documentation

## How it works
1. User opens the page.
2. Selects services from the list.
3. Service is added to the cart.
4. Total price updates automatically.
5. User fills booking details and submits.
6. EmailJS sends the booking request.
7. Confirmation message appears after success.

## Run it
Open `index.html` in a browser.

## Note
This is a frontend project and uses EmailJS for sending mail; real credentials must be added to the script for production use.
